[GitHub Pages 배포]
1. GitHub에서 새 저장소 만들기 (예: gift-ledger, Public)
2. 저장소 화면 > Add file > Upload files
3. zip을 풀고 "안의 파일 5개"를 한꺼번에 끌어다 놓기 (폴더째 올리지 않기)
4. 아래 Commit changes 클릭
5. Settings > Pages > Branch: main, 폴더: / (root) > Save
6. 1~2분 뒤 표시되는 주소(https://아이디.github.io/gift-ledger/)로 접속
7. 휴대폰 브라우저 메뉴에서 "홈 화면에 추가"

[처음 실행]
- PIN 4자리를 두 번 입력해 만듭니다.
- 2026.9.23 증여(10만 원 + 141만 원)와 매수 체결 내역이 미리 들어 있습니다.
- 증여자는 모두 "부"로 들어 있습니다. 실제 이체 명의자가 다르면 증여 탭에서 수정하세요.

[매매 자동 입력 (v1.2)]
- 알림 붙여넣기: 미래에셋 체결 알림을 [미래에셋증권]부터 복사해 붙여넣기. 여러 건 가능.
  같은 주문번호는 최종 체결 1건으로 합쳐지고, 계좌명으로 자녀가 자동 구분됩니다.
  '일부체결' 표시가 있으면 아직 전량 체결 알림이 오지 않은 것입니다.
- 캡처 사진 인식: 증권사 앱 [체결/미체결] 화면 캡처를 선택. 처음 한 번은 인식 도구를
  내려받느라 1분 정도 걸립니다. 화면의 '매수약정금액'과 인식 합계가 일치하는지 확인하세요.
  캡처 상단의 계좌번호와 자녀를 처음 한 번 연결해 저장하면, 다음부터 자녀가 자동 선택됩니다.
- 두 방식 모두 확인 화면에서 숫자를 확인한 뒤 저장됩니다.
